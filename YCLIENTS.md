# Интеграция с Yclients

Приложение умеет загружать данные напрямую из Yclients вместо Excel-файлов:

| Вкладка | Что загружается | Откуда в Yclients |
|---|---|---|
| 1. Финансовый отчёт | Финансовые операции (доходы, расходы, переводы) | `GET /transactions/{company_id}` |
| 2. Отчёт по услугам | Оказанные услуги с суммами, скидками и способами оплаты | `GET /records/{company_id}` |

Загруженные данные попадают в те же таблицы и расчёты, что и данные из файлов: классификация статей, зарплатная ведомость, залы, экспорт в Excel/Word работают без изменений. Загрузка файлов по-прежнему доступна.

## Настройка

1. Скопируйте `.env.example` в `.env` и заполните блок `YCLIENTS_*`:
   - `YCLIENTS_PARTNER_TOKEN` — партнёрский токен (раздел для разработчиков / Маркетплейс Yclients);
   - `YCLIENTS_USER_TOKEN` — токен пользователя с доступом к финансам и записям; либо задайте `YCLIENTS_LOGIN` и `YCLIENTS_PASSWORD`, тогда токен будет получен автоматически;
   - `YCLIENTS_COMPANY_ID` — ID филиала (число);
   - `YCLIENTS_CATEGORY_MAP` — необязательно, ручное сопоставление статей (см. ниже).
2. Установите зависимости и запустите: `npm install`, затем `npm run dev`.
3. На любой из вкладок выберите период и нажмите **«Загрузить из Yclients»**.

Токены хранятся только на сервере (`server.ts`) и в браузер не передаются: приложение обращается к Yclients через собственный прокси `/api/yclients/*`.

> **Важно:** запускайте приложение через `npm run dev` (разработка) или `npm run start` после `npm run build` (продакшен). Команда `npm run dev:client` запускает только Vite без сервера, и загрузка из Yclients в этом режиме работать не будет.

> **Безопасность:** прокси не требует авторизации, поэтому любой, кто открывает приложение, может получить финансовые данные салона. Не публикуйте приложение с заполненным `.env` в открытом доступе без защиты (VPN, авторизация на уровне хостинга и т. п.).

## Как данные сопоставляются

### Финансовые операции (вкладка 1)

- Приход определяется по положительной сумме, расход по отрицательной. В отчёт суммы передаются по модулю, как в файловой выписке.
- «Назначение» берётся из статьи операции Yclients. Для доходов названия приводятся к статьям шаблона: «абонемент» → «Доход от продажи абонементов», «сертификат» → «Выручка с сертификатов», «пополнение/депозит» → «Пополнение счёта», «товар» → «Выручка с товаров», доход по записи клиента → «Выручка с услуг». Остальное остаётся с названием статьи Yclients, а несопоставленные статьи приложение само выносит в дополнительные строки отчёта.
- Операции с «перевод» в названии статьи получают назначение «Перевод средств» и исключаются из P&L.
- «Контрагент»: сотрудник, иначе поставщик, иначе клиент. Для зарплатной ведомости выплаты сотрудникам должны быть привязаны к сотруднику в Yclients.
- «Услуга/Товар»: для доходов по записи берутся услуги этой записи. Если в записи несколько услуг, платёж делится между ними пропорционально стоимости.
- Свои соответствия статей задаются в `.env`: `YCLIENTS_CATEGORY_MAP='{"Статья в Yclients":"Статья в отчёте"}'`.

### Отчёт по услугам (вкладка 2)

- В отчёт попадают записи, где клиент пришёл (или запись оплачена полностью); удалённые записи пропускаются.
- Каждая услуга записи — отдельная строка. «Скидка» считается как разница между исходной ценой и ценой к оплате.
- Способы оплаты (баллы, абонементы, сертификаты, счета клиентов, деньги) определяются по названиям касс/счетов в финансовых операциях записи. Если Yclients их не вернул, вся сумма идёт в «Оплачено деньгами».

## Что проверить при первом запуске

Интеграция написана по описанию Yclients API v1 и проверена на тестовых данных, но не на живом аккаунте. После первой загрузки сверьте с отчётами Yclients:

1. Знак сумм: расходы должны приходить отрицательными. Если в вашем аккаунте они положительные, доходы и расходы определятся неверно (количество доходов и расходов видно в сообщении после загрузки).
2. Названия статей: посмотрите, какие статьи попали в дополнительные строки отчёта, и при необходимости добавьте их в `YCLIENTS_CATEGORY_MAP`.
3. Итоговая выручка по услугам и скидки против отчёта «Услуги» в Yclients.
